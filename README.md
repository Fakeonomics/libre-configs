## Метки в именах конфигов

В конце имени стоит метка источника — видно, откуда конфиг:

| Метка | Значение |
|-------|----------|
| (нет метки) | наш конфиг, проверен нашим замером трафика (3 этапа × 15 с, сервер в РФ) |
| `~` | из доверенного источника — проверен чужим пайплайном, берём как есть |
| `✓` | подтверждён вручную с мобильного |

Номер в имени постоянен между обновлениями: можно писать «номер 42 не работает».
